Os arquivos `gabarito_caps_01_05.md`, `gabarito_caps_06_10.md` e `gabarito_caps_11_14.tex` preservam respostas e padrões dos 210 IDs. Para cada objetiva, o diagnóstico A–E deve indicar a restrição contextual concreta: finalidade, grão, denominador, acesso, evidência, vigência, custo, latência, segurança ou qualidade. Não basta afirmar genericamente que a opção está errada.
